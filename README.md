# 엽록소는 왜 초록색이어야 해?

> 엽록소는 빨간빛과 파란빛을 흡수하고 초록빛을 반사한다.
> 그래서 식물은 초록색으로 보인다. 그런데 **꼭 초록이어야 했을까?**

세상에 있는 온갖 **초록**을 모았다. 이 이미지들에서 **초록인 부분만** 골라내서, 슬라이더로 원하는 색으로 바꿔볼 수 있는 작은 비주얼라이제이션이다.

초록색이면 보기 편한데, 노란색이나 보라색이면 이상하게 보기 불편한 느낌이 든다.

## 실행

```bash
npm run dev
# → http://localhost:5173
```

### 조작

| 컨트롤 | 하는 일 |
|---|---|
| **hue** | 초록 대신 들어갈 색 |
| **채도** | 바뀐 색의 선명도 (빨강은 조금 올려야 예쁘다) |
| **인식 범위** | 어디까지 초록으로 칠지. 올리면 옅은 초록이나 그림자 속 초록까지 잡힌다 |
| **마스크 보기** | 초록으로 인식된 영역을 흑백으로 보여준다 |
| 이미지에 마우스 올리기 | 원본 보기 |

## 어떻게 초록만 골라내나

### 1. RGB로는 초록을 제대로 구분할 수 없다
처음엔 가장 단순한 방법들을 비교했다.

| 방법 | 결과 |
|---|---|
| **ExG** (`2G − R − B`) | ❌ 노랑도 G값이 커서 같이 잡힌다. 모다피 머리가 보라색이 됐다 |
| **HSV hue 범위** | △ 연한 연두를 놓친다. 치코리타 몸통에 구멍이 뚫렸다 |
| **CIE Lab / LCh** | ✅ 사람 눈이 느끼는 색 거리에 맞춰진 색 공간이라 가장 자연스럽다 |

### 2. LCh 공간에서 마스크 만들기
픽셀을 `sRGB → linear → XYZ → Lab → LCh(명도 L, 채도 C, 색상각 H)` 순서로 변환한 뒤, 초록일 가능성을 0~1 사이 가중치 `w`로 계산한다.

```glsl
w = smoothstep(yLo, yLo + 10, H)          // 노랑 쪽 경계
  * (1 - smoothstep(cHi, cHi + 25, H))    // 청록 쪽 경계
  * smoothstep(c0, c1, C)                 // 무채색(회색·흰색)은 제외
```

- **경계를 비대칭으로 둔다.** 노랑은 LCh hue 100~110°, 잎은 120~150°에 몰려 있어서 노랑 쪽 경계는 좁게 잡는다. 청록 쪽은 이상해씨처럼 파란빛 도는 초록까지 들어오게 넓게 잡는다.
- **올리브 규칙.** 헐크 피부의 hue는 노랑과 거의 같다(90~110°). 대신 밝기가 다르다(헐크 L≈41, 모다피 머리 L≈91). 그래서 **어두울수록 노랑 쪽 경계를 내려서**, 올리브는 초록으로 치고 밝은 노랑은 보호한다.
- 0/1로 딱 자르지 않고 `smoothstep`으로 부드럽게 넘어가게 해서 잎 가장자리에 계단 현상이 생기지 않는다.

### 3. 색 바꾸기
명도 `L`은 그대로 두고 색상각 `H`만 목표 색으로 돌린다. 원래 초록 안에 있던 미세한 색 차이(연두↔진초록)는 35%만 남긴다. 그래야 잎이 한 가지 색으로 뭉개지지 않으면서, 목표 색에서 너무 벗어나지도 않는다.

```glsl
H' = targetHue + (H - 150°) * 0.35
C' = C * boost
out = mix(original, lab2rgb(L, C', H'), w)
```

이 계산은 전부 **WebGL 프래그먼트 셰이더**에서 돌아서 슬라이더를 움직이면 실시간으로 반영된다. 브라우저의 WebGL 컨텍스트 개수 제한을 피하려고, 오프스크린 컨텍스트 하나로 모든 이미지를 그린 다음 각 칸의 2D 캔버스에 복사한다.

## 이미지 추가하기

`images/` 폴더에 파일을 넣기만 하면 된다.

- `npm run dev`로 서버를 띄워두면 폴더를 감시한다. 파일을 추가·수정·삭제하면 **새로고침 없이** 페이지에 바로 반영된다 (Server-Sent Events).
- 새 파일은 `images.json` 맨 뒤에 자동으로 추가된다. 순서와 캡션(`alt` 텍스트)은 이 파일에서 고치면 된다.
- 다른 폴더를 직접 보고 싶으면 `IMAGES_DIR=/path/to/folder node server.mjs`로 띄운다. 만든 사람은 `npm run dev:desktop`으로 바탕화면 폴더를 보면서 포토샵으로 크롭했다.
- 서버 없이 정적 호스팅할 때는 `npm run gen`으로 `images.json`만 갱신하면 된다.

## 구조

```
chloroplast/
├── index.html            # 페이지 전체 (셰이더 + UI, 빌드 없음)
├── images/               # 초록색 친구들
├── images.json           # 이미지 순서 + 캡션
├── server.mjs            # 개발 서버: 정적 파일 + 폴더 감시 + SSE
└── scripts/
    ├── manifest.mjs      # images/ ↔ images.json 동기화
    └── gen-list.mjs      # 서버 없이 manifest만 갱신
```
